# Активный аудит — в разработке

Активная фаза (поднятие стенда, DAST, фаззинг API, эксплуатация) пока **не
реализована**. Не запускай активные инструменты (ZAP, schemathesis, garak против
живого таргета, эксплуатацию) по рабочему дереву или живым сервисам.

## Что запланировано

Отдельный flake поднимает одноразовую изолированную VM (microvm.nix / QEMU):
- полностью без сети наружу, единственный канал — host→VM для агента;
- проект разворачивается внутри копией, не оригиналом;
- снапшот до прогона, откат после; отчёты — через ro/rw-шару только на `.sec/reports`;
- внутри — активные инструменты против `localhost` VM.

Пока флейк не готов, активная часть не выполняется. Когда появится — этот скилл
опишет запуск и порядок.

## Сейчас

Делай пассивный аудит — [[sec-audit-passive]]. Он покрывает секреты, SAST, SCA,
IaC, SBOM и агентский слой без всякого стенда. Полная карта — [[sec-audit-all]].

Если Архитектор просит активную проверку прямо сейчас — скажи, что изолированный
стенд ещё не собран, и предложи либо дождаться его, либо ограничиться пассивной
фазой.
