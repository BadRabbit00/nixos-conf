> **Nix-first (this machine is NixOS, config in `~/nixos-conf`).** Everything is declarative: project tooling runs inside `nix develop -c <cmd>` (or direnv), one-off tools via `nix shell nixpkgs#<pkg> -c <cmd>`, builds via `nix build`. Never `pip install`, `npm -g`, `cargo install`, `brew`, `apt`, `nix-env`, `curl | sh`; declare the dependency in the flake instead. No inline interpreters (`python -c`, `node -e`): write a script file. Containers via `pkgs.dockerTools.buildLayeredImage`. Secrets via sops-nix into the devShell, never in `.nix` or git. Heavy builds throttled: `--max-jobs 4 --cores 4`. New files must be `git add`ed before Nix sees them. System changes go into `~/nixos-conf` and `sudo nixos-rebuild switch --flake .#badrabbitpc`, never into `/etc`.
