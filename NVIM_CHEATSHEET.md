# 🩸 Infernal Neovim Mecha-Cheatsheet

Этот файл содержит список горячих клавиш и возможностей твоей новой конфигурации Neovim для написания статей.

## ⌨️ Основные клавиши (General)
*   `SPACE` — твой **Leader key**. Большинство кастомных команд начинаются с него.
*   `:w` — сохранить файл (автоматически запускает **Prettier** и **Markdownlint**).
*   `u` — отмена действия (Undo).
*   `CTRL + R` — вернуть действие (Redo).

## 🧘 Режим концентрации (Concentration)
*   `<leader>z` — Переключить **Zen Mode**. Центрирует текст, скрывает лишние элементы и активирует **Twilight** (подсветка только текущего абзаца).

## 📝 Работа с Markdown
*   **Preview**: Превью в браузере открывается автоматически при входе в `.md` файл.
*   `<leader>i` — **Paste Image**. Вставляет изображение из буфера обмена, сохраняет его в папку `./images/` и прописывает путь в формате `![]()`.
*   **Авто-списки**: Просто нажми `Enter` внутри нумерованного или маркированного списка, и Neovim сам продолжит его.
*   **Word Count**: Счетчик слов отображается в статус-баре (внизу справа).

## 🧩 Сниппеты (Журнал «Хакер»)
Вводи код и нажимай `Enter` для развертывания блока. Используй `Tab` для перемещения между полями ввода.

*   `vzk` + `Enter` — Блок врезки `[viezka]`.
*   `code` + `Enter` — Блок кода `[code lang="..." title="..."]`.
*   `url` + `Enter` — Ссылка `[url=...]...[/url]`.
*   `warning` + `Enter` — Блок предупреждения `[warning]`.

## 🔄 Окружение (Surround)
Быстрое оборачивание текста (работает через `nvim-surround`):
*   `ysiw*` — Обернуть слово в `*курсив*`.
*   `ysiw_` — Обернуть слово в `_курсив_`.
*   `ds*` — Удалить окружающие `*`.
*   `cs*~` — Заменить окружающие `*` на `~`.

## 🎯 LSP и Навигация (Marksman)
*   `gd` — Перейти к определению ссылки/заголовка.
*   `K` — Показать документацию/информацию под курсором.
*   `CTRL + Space` — Вызвать меню автодополнения вручную.
*   `Enter` — Подтвердить выбор в меню дополнения.

## 🌍 Проверка орфографии (Spellcheck)
*   Включена по умолчанию для **Русского** и **Английского**.
*   `z=` — Показать варианты исправления слова под курсором.
*   `zg` — Добавить слово в словарь (хорошее).
*   `zw` — Пометить слово как неправильное (плохое).
*   `[s` / `]s` — Перейти к предыдущей/следующей ошибке.
